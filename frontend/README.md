# MERN Task Manager

A full-stack Task Manager application built using the MERN stack.

## Features

- Add new tasks
- View all tasks
- Update tasks
- Delete tasks
- Mark tasks as completed
- Set task priority
- Add due dates and categories
- MongoDB database integration

## Technologies Used

- MongoDB
- Express.js
- React.js
- Node.js
- CSS
- Git & GitHub

## Installation

### 1. Clone the repository

git clone https://github.com/Sharik252/mern-task-manager.git

### 2. Backend Setup

cd mern-task-manager/backend

npm install

Create a `.env` file and add:

MONGO_URI=your_mongodb_connection_string
PORT=5000

Start backend:

node server.js

### 3. Frontend Setup

Open a new terminal:

cd mern-task-manager/frontend

npm install

npm run dev
